ROBCO OS v2.0
Аутентичная веб-оболочка в стиле ретро-футуризма (Fallout-style), предназначенная для написания и тестирования JavaScript кода прямо в браузере. Проект реализован как PWA, что позволяет устанавливать его на Android и iOS как полноценное приложение.

⚡ Особенности
Чистый стек: Только Vanilla JS, HTML5 и CSS3. Никаких React, Vue или jQuery.

PWA Ready: Полная поддержка манифеста и иконок для установки на смартфон.

Терминал: Интерактивная среда выполнения кода через eval().

Лаборатория: Отдельный экран для экспериментов с кодом.

Темы: Несколько цветовых схем (Amber, Green, White, Red), переключаемых одной кнопкой.

Эффект CRT: Стилизация под старые мониторы с разверткой и помехами.

📦 Зависимости и Библиотеки
Этот проект придерживается философии "Zero-Dependency". Тебе не нужно ничего устанавливать через npm или yarn для работы фронтенда.

Шрифты: Используется Google Fonts (VT323) — подключается автоматически через CSS.

Иконки: Встроены в проект (папка icons).

API: Для работы чата с ИИ используется стандартный браузерный fetch.

🛠 Что нужно скачать/установить для запуска?
VS Code (или любой редактор) — для правки кода.

Live Server (расширение для VS Code) — рекомендуется. Для корректной работы PWA и Service Workers проект должен открываться через http://, а не через file://.

Node.js (опционально) — если захочешь развернуть проект на хостинге типа Vercel или Netlify.

🚀 Как запустить локально
Склонируй репозиторий:

Bash
git clone https://github.com/nettaisdead/fallout-terminal.git
Открой папку в VS Code.

Нажми "Go Live" в нижнем углу редактора (если установлен Live Server).

Открой http://127.0.0.1:5500 в браузере.

📁 Структура проекта
index.html — скелет интерфейса и структура вкладок.

style.css — вся магия CRT-эффекта, анимации помех и темы.

script.js — логика переключения экранов, выполнения кода и обработки ввода.

manifest.json — настройки для превращения сайта в приложение (PWA).
